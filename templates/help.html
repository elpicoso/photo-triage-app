How to use this

← back to folders
1

Navigate to a shoot folder

Click through folders until you reach one that directly contains RAW files. It'll show an amber-bordered card with a status and an action button.

not started
2

Extract previews

Confirm the RAW extension matches this shoot's camera (defaults to CR2), then click Extract. Pulls the embedded JPEG preview out of each RAW file — fast, no RAW processing happens.

extracted
3

Run triage

Sends the extracted previews to Claude in small batches to flag technical rejects, assign star ratings, and generate keywords.

triaged - needs review
4

Review results

Click through to the editable table. Check ratings and keywords against the actual images before submitting — this is the checkpoint that catches anything Claude got wrong before it's written anywhere permanent.

5

Write to XMP

Writes your (possibly edited) ratings and keywords into XMP sidecar files next to each RAW.

written
6

Import into Lightroom

Back on your Mac: select the folder in Lightroom, then Metadata → Read Metadata from File. This step can't be automated from here — Lightroom only runs on the Mac.

Before trusting a big batch: spot-check one file's XMP output first. On the Pi: exiftool -G1 -a -s path/to/file.xmp — confirm Rating, Subject, and Keywords all show real values.
